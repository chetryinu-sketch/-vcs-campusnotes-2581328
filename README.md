# Campus Notes

## Project Overview

This repository contains academic notes and learning materials related to Git, GitHub, and Version Control Systems.

## Repository Contents

- **notes.txt** – Contains introductory notes about Git and GitHub.
- **subjects.txt** – Contains a list of academic subjects.
- **README.md** – Provides information about the project.

## Technologies Used

- Git
- GitHub
- Visual Studio Code
- Markdown

## Git Operations Practised

1. Initialising a Git repository
2. Creating and managing commits
3. Working with branches
4. Pushing and pulling changes
5. Cloning repositories
6. Collaborating through pull requests

## Project Purpose

The purpose of this repository is to practise version control, maintain academic notes, and understand collaborative software development using Git and GitHub.
